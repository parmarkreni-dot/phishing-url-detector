# 🎣 Phishing URL Detector

## 📌 Project Overview

Phishing URL Detector is a web-based cyber security project developed using HTML, CSS, and JavaScript.

The tool analyzes a URL and identifies common phishing indicators to help users recognize potentially malicious websites.

---

## 🚀 Features

- URL Risk Analysis
- Phishing Detection Logic
- Risk Score Calculation
- Suspicious Keyword Detection
- HTTP vs HTTPS Check
- IP Address Detection
- Long URL Detection
- User-Friendly Interface
- Responsive Design

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript

---

## 🔍 Detection Parameters

The tool checks for:

- Use of HTTP instead of HTTPS
- Presence of IP Addresses
- Suspicious Keywords
- Excessive URL Length
- Special Characters
- Common Phishing Patterns

---

## 📊 Risk Levels

| Risk Score | Status |
|------------|---------|
| 0-1 | Safe |
| 2-3 | Suspicious |
| 4-5 | High Risk |

---

## 🎯 Purpose

The purpose of this project is to demonstrate basic phishing detection techniques and improve cyber security awareness among users.

---

## 📚 Cyber Security Concepts Used

- Phishing Detection
- URL Analysis
- Risk Assessment
- Security Awareness
- JavaScript Logic Implementation
